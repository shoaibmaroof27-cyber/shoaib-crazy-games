SHOAIB CRAZY GAMES — RUN IN VS CODE

1. Extract this ZIP.
2. Open the extracted Shoaib_Crazy_Games folder in VS Code.
3. Install the VS Code extension "Live Server" by Ritwick Dey.
4. Open index.html, right-click, then choose "Open with Live Server".
5. Your browser opens the site.

Included:
- Neon Car Racer: playable in this project.
- Target Pop: playable in this project.
- Hazmob: opens the official Hazmob site (internet required).

No Node.js, npm, or backend is required for this starter. Games run in your browser.
